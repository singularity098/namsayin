### NAMsayin
- An LV2/VST3 plugin written in C++ using DPF and NeuralAmpModelerCore (no standalone application for now)
- The plugin is ultra-light, fast, and snappy
- Zero latency by default: latency (plugin delay compensation, PDC) is only introduced by blocks that require it, and is reported to the host
- Natively runs on Linux and Windows, x86-64 only, and requires a CPU with AVX2/FMA (macOS and ARM are not supported for now)
- Beautiful interface with a very dark theme, drawn with NanoVG: the window background is the owner's dark wood image (generated with Krea-2 in ComfyUI; shown only behind the panels; 2026-10-22), and boxes (bars, panels, tiles, buttons, dialogs) are black inside with an ultra-thin gray outline (no gradient). Font: Jost Light. Knobs: a black body with a hairline edge, a scale of ticks lit up to the value, and a dot marking the position (owner's choice from drafted options, 2026-10-22)
    - The highlight colour is configurable in Settings; blue by default (owner's choice, 2026-10-22; was purple)
- The interface can be resized and scales for high DPI displays
- Free, open source software under the MIT license
- Supports NAM A1 and A2
  - A2 is the 2026 NAM architecture; one A2 file can run in Full or Lite (lower CPU) mode
- Supports an IR cab loader
- Settings panel where the user can:
    - Specify the directory for NAM files and separately for IR files, with refresh/rescan button
    - Select NAM A2 size, lite or full (global default)
    - Add per-block NAM A2 size, if desired (overrides the global default)
    - Turn on per-block volume normalization, using the loudness metadata in NAM files; IRs can also be normalized
    - Multi-core processing: the two parallel branches of a split run on separate cores
- Settings and favorites are stored in one global config file per user, shared by all plugin instances
- The scanner for NAM and IR files is able to see inside of zip files and load those files as if they were already extracted
- Allows user to star/favorite NAM files in the interface. Favorites are tied to the file's content hash, so they survive the file being moved or renamed
- Has a built-in very high performance and high accuracy tuner, with traditional or strobe modes. The tuner can be toggled on with a button in the top-right of the window.  The guitar sound is by default muted when the tuner is engaged, but the mute also can be toggled on or off
    - The tuner reads the dry input (before the signal chain), with a gain boost so that quiet inputs are not a problem
    - Adjustable reference pitch (A4 = 415–466 Hz, default 440)
    - Drawn in the knobs' style: a hairline tick scale lit from the centre to the pitch with a dot for the needle; the strobe's bands are tick lines (owner's request, 2026-10-23)
    - Accuracy target: ±0.1 cent, from a 5-string bass's low B (31 Hz) up to the 24th fret of a guitar's high E string
- Also has a built-in metronome which can be toggled on and off from a button next to the tuner. It has the same features as the metronome in Fretbored (https://github.com/singularity098/fretbored):
    - Tempo 20–300 BPM, tap tempo
    - Meter: 1–16 beats over 2, 4, 8 or 16; beat grouping for compound/odd meters (e.g. 7/8 as 2+2+3)
    - Per-beat accents: accent / normal / soft / mute
    - Subdivisions: eighths, triplets, sixteenths, quintuplets, sextuplets, swing, dotted, and mixed 8th/16th figures
    - Sounds: Classic, Digital and Beep; separate volume for subdivisions. All generated in code, no samples (owner, 2026-10-23: so they are our own; Classic recreates the click the owner supplied)
    - Trainer: Step mode (+N BPM every M bars from start to end tempo) and Gradual mode (smooth ramp over N bars); works for slowing down too
    - Gap trainer: play N bars, then mute M bars
    - Visual pulse synced to what you hear (the swinging pendulum ball was removed: at host redraw rates it looked choppy; owner's request, 2026-10-23)
    - Sample-accurate timing
    - Tempo is independent of the DAW by default; a switch syncs tempo and transport to the DAW instead
    - Keyboard shortcuts only apply while the plugin window has focus
- Has a linear signal chain which runs from left to right, where users can add NAM, IR, or built-in effects, up to a maximum of 32 blocks
- Near the metronome and tuner is another button which links to my other free application Fretbored: https://singularity098.github.io/fretbored/
- The buttons at the top right of the window (Fretbored, metronome, tuner, settings, bypass) are icons that show what they do; the Fretbored button uses the Fretbored app icon (owner's request, 2026-10-22)
- Every knob and control has a highly detailed but easy to understand plain-English explanation of what it does and how to use it, shown in a translucent popup when the mouse hovers over it (owner's request, 2026-10-22)
- The signal chain may be split into 2 at any point, and then merged back into 1 at any other point, allowing for effects to run in parallel, or multiple NAM simultaneously
    - Only one split at a time
    - A small split icon appears on the signal line between blocks while the mouse is over the gap; clicking it adds an empty split there (owner's request, 2026-10-22)
    - The merge has controls for A/B balance, level, pan and phase invert per branch
    - The two branches are time-aligned at the merge if their latencies differ
- The blocks in the signal chain are square shaped, and we will use provided images (later possibly as small thumbnails on the tiles)
- The panel below the chain shows the selected block: a large, high-quality image of the pedal/amp/cab on the left of the panel, and the block's generic knobs right-justified next to it. Until real images exist, a drawn placeholder (pedal, amp head or cab) is shown, in the "Neon" style (black enclosure outlined in glowing lines of the category colour, with a symbol on its face that is unique to each pedal and drawn from its name and purpose (owner's request, 2026-10-23; the Doubler's photo was removed so every block has the same neon look); owner's pick from six mockups; the second style, "Panel", was removed at the owner's request, 2026-10-23) Later the generic knobs may be removed so knobs are turned on the image itself (needs images prepared by the owner first)
- A local NAM file or IR uses an image sidecar file with the same name (e.g. `My Amp.nam` → `My Amp.png`). When there is no sidecar image, we will use a generic image. In the beginning, we can use a very crude mockup and I will provide higher quality images later
    - Sidecar images can be 8-bit PNG or JPEG (16-bit PNG isn't supported by the UI's image decoder)
- Blocks can be easily reordered by dragging and dropping. They can also be temporarily disabled/bypassed, or removed
- Undo/redo for all edits to the signal chain and block settings
- Codebase is designed such that effects are modular and easy to add or remove from the program as we get new ideas
- MIDI control and DAW automation:
    - Each block occupies a fixed slot with a fixed set of host parameters, so every block parameter can be automated by the DAW and controlled by MIDI (MIDI learn)
    - A block keeps its slot when it is reordered, so automation and MIDI mappings follow the block, not its position
- ~~Has completely optional Tone3000.com integration for NAM~~ Dropped, with its three Add Block categories (owner's decision, 2026-10-23)
- To add a new block, the user will click on a "+" box in the signal chain and it will bring up an Add Block dialog which has categories which can be selected on the left-hand side, and then the user selects:
    - NAM (was "Local NAM"; renamed by the owner, 2026-10-23)
    - IR (was "Local IR")
    - Distortion
    - Dynamics
    - EQ
    - Modulation
    - Reverb
    - Delay
    - Pitch
    - Synth (split from "Pitch/Synth", which had grown too cluttered, with its own pedal colour, magenta; owner's request, 2026-10-23)
    - Filter
    - Wah
    - A search box at the top of the dialog searches every category at once (built-in blocks, NAM models and IRs); search boxes have an × to clear them (owner's request, 2026-10-22)
    - Text fields edit like normal text boxes: click to place the cursor, drag or Shift to select, double-click selects a word, Ctrl+Backspace/Delete remove a word, Ctrl+Left/Right move by word, Home/End, Ctrl+A/C/X/V (owner's request, 2026-10-23)
    - NAM and IR list the library folder as it's organised: subfolders (and zips) first, opened with a click, and an Up button to go back up; Favorites lists every favorite from all folders (owner's request, 2026-10-23)
    - The block panel's large pedal art doesn't repeat the block's name, which the panel already shows (owner's request, 2026-10-23)
- A menu is present at the top of the application to save and load presets
    - Saving keeps presets in the plugin's own preset folder (subfolders allowed), named in an in-app dialog rather than the system save dialog, and without embedded files (owner's decision, 2026-10-22)
    - Export writes a copy anywhere with the system save dialog; exported presets can embed everything they use (NAM files, IRs, images), so they can be shared
    - One saved preset can be marked as the default; new plugin instances load it
    - The preset menu lists the saved presets as they're arranged in folders, instead of a Recent list (owner's decision, 2026-10-22)
    - When a preset references a NAM or IR file that no longer exists, the block is still added but grayed out, with a button to locate the file
- Global bypass button
- At the bottom of the application, we have:
    - Input mode toggle (mono/stereo). Stereo processes both channels (double CPU) and allows stereo effects such as stereo delay
    - Input (level) knob
    - Bass, Middle and Treble knobs: a global EQ at the end of the chain
    - Output (level) knob
    - Input and output meters, with a clip indicator
    - Output limiter

### Version 1 scope
- Local NAM blocks
- Local IR blocks (cab impulse responses from .wav files), added to the prototype at the owner's request
- Delay block (with stereo delay)
- Doppelganger Delay block (the owner's idea): echoes alternate between a thick flanger (odd echoes) and a thick chorus (even echoes), each echo with only its own effect; all parameters configurable. Blocks have up to 16 parameters.
- Reverb block (room, hall and plate types)
- Compressor block (studio style: threshold, ratio, attack, release, knee, makeup, mix, with a gain-reduction meter), added to M3 at the owner's request
- Everything else in this document (IR loader, other effect categories, etc.) follows in later versions, but the architecture must allow for it
